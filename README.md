# Math Trainer

a yazi-style terminal math simulator with panels, statistics, and answer history.

## Install

'''bash
npm install -g git+https://github.com/Llaawliett/math-trainer.git

## Launch

mathTrainer

## Features

- Addition, subtraction, multiplication, division
- Squaring
- Decimals on medium and high difficulty
- Guarantee of non-repetitive tasks within the session
- Full-screen terminal interface (blessed)

## Controls

- Enter — send answer
- Esc / Ctrl+C — quit
